# Milestone: v0.1.0 - MVP Release

## Goal
Deliver a minimal viable product with basic three-tier routing functionality.

## Target Date
TBD

## Scope

### In Scope
- Basic Tier 1 routing to Home Assistant conversation agent
- Simple Tier 2 filter (placeholder logic)
- Basic Tier 3 routing to single cloud provider
- Configuration flow for setup
- Basic error handling and fallback
- Unit tests for core functionality
- HACS compatibility

### Out of Scope
- Advanced filtering rules
- Multiple cloud provider support
- Analytics and metrics
- Custom filter plugins
- Performance optimizations
